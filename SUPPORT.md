# Getting help

- **Installing and running NeoDesk:** the [documentation](https://docs.neode.sk),
  starting with [Troubleshooting](https://docs.neode.sk/operations/troubleshooting/).
- **A question, a bug or an idea:** ask on the
  [NeoDesk Discord](https://discord.gg/nwERSawufr) or in
  [GitHub Discussions](https://github.com/neodeskapp/neodesk/discussions).
  Say which version you run, how it is installed and what you see.
- **A security problem:** follow the [security policy](SECURITY.md). Don't
  post it in public.
- **The stock RustDesk client:** if a problem also happens with RustDesk's
  own server, it belongs to [RustDesk](https://github.com/rustdesk/rustdesk).

There is no paid support and no guaranteed response time.
