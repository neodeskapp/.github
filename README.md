# neodeskapp/.github

The organization profile and the default community files for every
neodeskapp repository that has none of its own.

- `profile/README.md`: the page at <https://github.com/neodeskapp>, with its
  images in `profile/img/` and its badges in `profile/badges/`.
- `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md` and
  `pull_request_template.md`: GitHub shows these in a repository unless it
  has its own file of the same kind.

The hero and the console graphic are copies of `docs/assets/readme/` in
[neodesk](https://github.com/neodeskapp/neodesk), and the client screenshot
is `screen-home-*.png` from
[neodesk-client](https://github.com/neodeskapp/neodesk-client). Copy them
again when those change.
